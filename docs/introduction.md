# 项目介绍

`Lava` 是一套一致, 安全, 开箱即用的 Java 基础设施工具库, 面向服务端项目中的常用基础设施场景.

## 解决什么问题

很多业务项目都会反复处理 JSON, HTTP, 加密, JWT, 调度, 邮件, ID, 时间和 IO 等基础能力. 如果每个项目都单独选择和封装, 容易出现
API 风格不一致, 配置分散, 默认行为不统一和排查成本高的问题.

`Lava` 的目标是把这些常用能力整理成一组可复用模块, 让团队在不同项目里保持接近的使用方式和默认约定.

## 适合什么场景

| 场景                         | 模块            |
|------------------------------|-----------------|
| 基础工具, 重试, 时间, ID, IO | `lava-core`     |
| JSON 编解码和配置            | `lava-json`     |
| 同步 HTTP 调用               | `lava-http`     |
| 密码哈希和密钥处理           | `lava-crypto`   |
| JWT 签发与验签               | `lava-jwt`      |
| 后台任务调度                 | `lava-schedule` |
| 邮件发送和收取               | `lava-mail`     |
| 多模块依赖版本管理           | `lava-bom`      |

## 设计取向

- **一致**: 各模块尽量保持相近的入口, 命名和配置方式.
- **安全**: 涉及密码, token, 私钥, 时间和网络调用的场景, 优先给出稳妥默认建议.
- **开箱即用**: 常见场景提供直接可用的封装, 复杂需求再进入对应模块文档.
- **按需组合**: 每个能力独立成模块, 项目只引入需要的部分.
