# TimeUtil 时间解析

`TimeUtil` 用于把常见日期或日期时间字符串解析为 `LocalDateTime`.

## 最小可运行示例

```java
import com.zhengshuyun.lava.core.time.TimeUtil;

import java.time.LocalDateTime;

public class TimeUtilDemo {

    public static void main(String[] args) {
        LocalDateTime time1 = TimeUtil.parse("2026-02-08 10:30:00");
        LocalDateTime time2 = TimeUtil.parse("2026/02/08 10:30:00.123");
        LocalDateTime time3 = TimeUtil.parse("20260208");

        // TODO: 按业务处理 time1/time2/time3
    }
}
```

- `parse(...)`: 解析失败或输入为空时返回 `null`.
- 只有日期没有时间时, 时间部分默认是 `00:00:00`.

## 支持格式

| 类型             | 示例                      |
|------------------|---------------------------|
| 标准日期时间     | `2026-02-08 10:30:00`     |
| 带毫秒日期时间   | `2026-02-08 10:30:00.123` |
| 斜杠日期时间     | `2026/02/08 10:30:00`     |
| 紧凑日期时间     | `20260208103000`          |
| ISO 本地日期时间 | `2026-02-08T10:30:00`     |
| 标准日期         | `2026-02-08`              |
| 斜杠日期         | `2026/02/08`              |
| 紧凑日期         | `20260208`                |

## 常见坑与排查建议

| 异常/消息            | 原因                           | 解决方式                                   |
|----------------------|--------------------------------|--------------------------------------------|
| 返回 `null`          | 输入为空或格式不在支持范围内   | 先打印原始字符串, 检查空格, 分隔符和毫秒位 |
| 日期正确但时间是零点 | 输入只有日期部分               | 业务需要精确时间时, 要求调用方传入日期时间 |
| 时区结果不符合预期   | `LocalDateTime` 本身不包含时区 | 时区转换放在业务边界统一处理               |
